## Not verified in the build environment

These are stated plainly because they could not be exercised here:

- **Docker image build.** No Docker daemon was available. The `Dockerfile` is written against the Playwright 1.56.0 image and has not been built or run.
- **A real public website.** The build sandbox has no direct outbound network path for the auditor (it deliberately does not use an upstream proxy), so live-site behaviour (real CDNs, real WAF challenges, real TLS chains, real DNS) was not observed. Fixture challenges imitate Cloudflare-style markers only.
- **The real CrUX API and a real LLM.** Both were exercised against local mock endpoints that follow the documented request and response shapes. The LLM client uses the Anthropic Messages API shape; no model name is assumed, so `LLM_MODEL` must be set by the operator.
- **The Wellows application.** No repository was supplied. Auth, the client/project model, navigation, components and tokens are the documented fallbacks, not the app's real ones.
- **Source registry.** 22 of the 37 sources were re-fetched and checked on 2026-10-05 (Google AI features, robots.txt, HTTP status, canonical, robots meta, hreflang, search gallery, Organization, Article, Breadcrumb, Local business, Product snippet, Software app, Event, Profile page, FAQ removal, Web Vitals, CrUX API, OpenAI, Anthropic, Perplexity, Google-Extended). One entry is the tool-policy label itself. The remaining 14 carry a "seeded, not re-fetched" note in `docs/SOURCES.md`.
- **Scale and long-run behaviour.** Concurrency above one audit, large sites (300+ links per document), and multi-day operation were not load tested.
- **Report language.** English only; the `report_language` input is stored but no translation is implemented.

## Known limits of the checks

- Lab diagnostics use Chromium PerformanceObserver measurements with CPU and network throttling, not Lighthouse. They are unscored.
- Page-type labels and the "material" thresholds for RAW-versus-RENDERED differences are Wellows tool policy and are labelled as such wherever they appear.
- Hreflang declared only in a sitemap cannot be validated, by design: the audit never reads sitemap contents.
